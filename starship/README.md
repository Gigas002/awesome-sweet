# Sweet-Starship

Sweet palette for [starship](https://github.com/starship/starship) prompt

`Sweet.toml` defines a `Sweet` [palette](https://starship.rs/config/#palette): starship's named colors (`green`, `bold cyan`, `bright-red`...) become Sweet's, whatever your terminal's colors are

## Requirements

There's none, it's a color scheme

**Optional**

- A Nerd Font (e.g. `CaskaydiaCove Nerd Font Mono`), for the symbols in the [example](example/starship.toml)

## Installation

Copy the contents of `Sweet.toml` into your starship config, `~/.config/starship.toml` (or the file `$STARSHIP_CONFIG` points to). See [example](example/starship.toml) for a complete config
