# Sweet-ashell

Sweet theme for [ashell](https://github.com/MalpenZibo/ashell)

## Requirements

- ashell 0.5 or newer (TOML config; older versions read `~/.config/ashell.yml`)

## Installation

Copy the `Sweet.toml` contents into `~/.config/ashell/config.toml`. See `example` for a complete config
